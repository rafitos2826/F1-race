# F1 Racing (Browser)

Jogo simples de corrida F1 feito em HTML5 + JavaScript. Pronto para rodar no navegador e publicar no GitHub Pages.

Descrição
- Jogo top-down: controle um carro de F1 passando por outros carros/obstáculos.
- Pontuação por distância; recorde salvo no localStorage.

Como rodar localmente
1. Coloque os arquivos `index.html`, `style.css`, `game.js` na mesma pasta.
2. Abra `index.html` no navegador (duplo clique).

Controles
- ← / A : mover para a esquerda
- → / D : mover para a direita
- ↑ / W : acelerar
- S : frear
- R : reiniciar

Publicar no GitHub Pages
1. Crie um repositório (ex.: `f1-racing`) e faça commit dos arquivos.
2. Vá em Settings → Pages e configure a branch `main` (ou `master`) e a pasta `/ (root)` como source.
3. Salve; em alguns minutos seu site estará em `https://<seu-usuario>.github.io/<nome-do-repo>/`.
